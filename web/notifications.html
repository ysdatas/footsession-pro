Sur cet appareil

Comment les joueurs les activent

  1. iPhone (iOS 16.4 ou plus récent) : ouvrir le site dans Safari, toucher Partager puis « Sur l’écran d’accueil ».
  2. Ouvrir LMFC depuis la nouvelle icône et se connecter.
  3. Sur l’accueil, toucher « Activer » puis « Autoriser ».
  4. Android : sur l’accueil du site dans Chrome, toucher « Activer » puis « Autoriser ». L’ajout à l’écran d’accueil est conseillé.

Le message n’est pas gardé dans l’application : un joueur qui n’a pas activé les notifications ne le reçoit pas.
